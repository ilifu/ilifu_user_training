Session 3 — Parallelism

What You'll Learn

Tutorial 1 — Parallel Scaling

  • MPI (Message Passing Interface) concepts: Scatterv, Reduce, ranks
  • Setup: module load openmpi + uv venv
  • Four configurations of one Python program: 1, 4 and 8 MPI processes on one node, then 8 across 2 nodes
  • C++ demos comparing pure MPI, OpenMP and hybrid MPI+OpenMP
  • Key lesson: inter-node communication overhead can outweigh the gain — keep jobs on one node when they fit

Tutorial 2 — Profiling

  • Live monitoring with sstat and htop
  • Post-job analysis: sacct, seff
  • Wall-time efficiency and memory efficiency

Tutorial 3 — Efficient High-throughput Jobs

  • Example result: combined job at 28% memory efficiency vs. split jobs at 75–70%
  • Slurm job dependencies with afterok
  • Automatic dependency submission scripts

Prerequisites

  • Sessions 1 & 2, or equivalent experience
  • Setup provided on ilifu: uv and the OpenMPI C++ compiler wrapper (mpic++)
Cluster context: ilifu uses Gigabit Ethernet between nodes — high bandwidth, but not the low-latency InfiniBand found on some HPC clusters. The multi-node scaling results in Tutorial 1 reflect this real-world constraint — a deliberate teaching point.
